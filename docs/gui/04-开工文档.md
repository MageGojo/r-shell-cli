## 4. 任务分解(逐项含验收)

### T1 — Flutter 桌面脚手架
- 在仓库根创建:`flutter create --platforms=macos,windows,linux desktop`
- 设置应用名 `R-Shell`、最小窗口尺寸(1040×640,用 `window_manager`)、深色背景避免白闪。
- **验收**:`cd desktop && flutter run -d macos` 出现空窗口,无报错。

### T2 — `r-shell-bridge` crate 接入 workspace
- 由 frb 集成生成 `desktop/rust`(见 T3),其 `Cargo.toml`:
  ```toml
  [package]
  name = "r-shell-bridge"
  edition = "2024"
  [lib]
  crate-type = ["cdylib", "staticlib"]
  [dependencies]
  r-shell-core = { path = "../../core" }
  flutter_rust_bridge = "2"
  ```
- 根 `Cargo.toml` 的 `members` 加入 `"desktop/rust"`。
- **验收**:`cargo build -p r-shell-bridge` 通过;`cargo build --workspace` 全绿(core/cli 零回归)。

### T3 — flutter_rust_bridge 集成与 codegen
- 在 `desktop/` 执行 `flutter_rust_bridge_codegen integrate`(生成 `rust/`、`flutter_rust_bridge.yaml`、cargokit 构建钩子、`lib/src/rust/`)。
- 配置 `flutter_rust_bridge.yaml` 指向 `rust/src/api`。
- cargokit 让 `flutter build/run` 时**自动编译** Rust 产物,无需手动 cargo。
- **验收**:frb 自带示例 `greet()` 能从 Dart 调通并显示返回值。

### T4 — 第一个真业务 API:连接列表(脱敏)
- 在 `desktop/rust/src/api/connections.rs`:
  ```rust
  use flutter_rust_bridge::frb;

  #[frb(dart_metadata=("freezed"))]
  pub struct ConnectionDto {
      pub id: String,
      pub name: String,
      pub host: String,
      pub port: u16,
      pub username: String,
      pub folder: String,
      pub auth_method: String,   // "password" | "publickey"
      pub status: String,        // ConnectionStatus.label()
      pub has_password: bool,
      pub has_private_key_path: bool,
  }

  /// 读取本地 workspace.json,返回脱敏连接列表(复用 core::storage + model)。
  pub fn list_connections() -> Vec<ConnectionDto> {
      r_shell_core::storage::load_workspace()
          .connections
          .iter()
          .map(ConnectionDto::from_saved)   // 仅取脱敏字段,绝不含明文密码/私钥
          .collect()
  }
  ```
- `from_saved` 映射 core `SavedConnection`,**只取脱敏字段**(对齐 [03 §11](03-UI设计规范.md))。
- 重新 `flutter_rust_bridge_codegen generate`。
- **验收**:Dart 侧 `await api.listConnections()` 返回真实 `workspace.json` 的连接;返回结构里**无任何明文密码/私钥字段**(代码评审确认)。

### T5 — 主题骨架(落地 03 设计规范)
- 新建 `shared/theme/`:`AppColors`(§12 已给)、`AppSpacing`、`AppRadius`、`AppTextStyles`、`AppTheme`(组装成 `ThemeData`,深色)。
- `pubspec.yaml` 内置 Inter / JetBrains Mono 字体,主题 `fontFamily: Inter`。
- **验收**:全局背景、文字色、强调色取自 token;无组件写死 hex。

### T6 — 三栏外壳 + 连接树渲染(最小闭环核心)
- `features/shell/app_scaffold.dart`:实现 [03 §6](03-UI设计规范.md) 布局——图标导航栏(56)+ 连接树侧栏(260,可拖)+ 中心占位(空状态「选择左侧连接开始」)+ 监控侧栏(300,占位可折叠)+ 状态栏(28)。
- `features/connections/`:
  - `connections_provider.dart`(Riverpod):`FutureProvider` 调 `ConnectionsRepository.list()`。
  - `connection_tree.dart`:按 `folder` 分组折叠;每项渲染状态点(映射 status)+ 名称 + `user@host`(mono, muted);悬浮/选中态按 [03 §7](03-UI设计规范.md)。
  - 搜索框按名称/host 过滤。
- **验收**:启动后左侧出现真实分组连接树;点击项高亮;状态点颜色对应 `ConnectionStatus`;与主界面稿 `design/rshell-ui-01-main.png` 左栏视觉一致。

### T7 — 三平台冒烟
- macOS / Windows / Linux 各 `flutter run` 一次,确认:窗口正常、连接树渲染、无 frb 链接错误。
- **验收**:三平台都能起、都能看到连接树(至少 macOS 必过;Win/Linux 记录已知问题)。

## 5. 数据流(Stage 1)

```text
workspace.json
   │  core::storage::load_workspace() + model::SavedConnection
   ▼
r-shell-bridge: list_connections() -> Vec<ConnectionDto>   (脱敏)
   │  flutter_rust_bridge (FFI, async)
   ▼
ConnectionsRepository (bridge/)  →  connectionsProvider (Riverpod)
   │
   ▼
ConnectionTree widget  →  渲染分组 + 状态点 + user@host
```

## 7. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| frb codegen / cargokit 首次集成卡顿 | 先用 frb 模板 `greet()` 跑通再接业务;严格对齐 frb v2 文档版本 |
| workspace 加入 `desktop/rust` 影响 CLI 构建 | 每步跑 `cargo build --workspace` + `cargo test -p r-shell-core` 保零回归 |
| 凭据泄漏到 Dart 层 | DTO 只取脱敏字段;评审 `from_saved`;沿用 core 脱敏策略 |
| 三平台字体/窗口差异 | Stage 1 即三平台冒烟;字体随包内置不依赖系统 |
| 大图标/字体包体积 | v1 可接受(Flutter 本就较大);后续按需裁剪 |

> 关联技术债(非本阶段阻塞,见 [进度.md](进度.md)):workspace 化后 `packaging/`(`create_dmg.sh`、`release.yml`)与 `scripts/bump-version.*` 仍引用旧的 `cli/target` / `cli/Cargo.lock` 路径,**发版前需修**(产物现在在仓库根 `target/`)。Stage 7 打包时一并处理。

## 9. 开工即用命令清单

```bash
# 0. 校验工具链
flutter --version && cargo --version && flutter_rust_bridge_codegen --version

# 1. 脚手架
flutter create --platforms=macos,windows,linux desktop

# 2. frb 集成(在 desktop/ 下)
cd desktop && flutter_rust_bridge_codegen integrate

# 3. 改 desktop/rust/Cargo.toml 依赖 ../../core;根 Cargo.toml members 加 "desktop/rust"
cargo build --workspace        # 确认零回归

# 4. 写 api/connections.rs 后重新生成绑定
flutter_rust_bridge_codegen generate

# 5. 跑起来
flutter run -d macos
```
